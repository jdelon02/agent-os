## Usage

Commands can be invoked either:
1. **Direct reference:** Follow the markdown file workflow manually
2. **Slash commands:** Use `/analyze-product`, `/create-spec`, etc. for automated execution
3. **File references:** Include `@.github/commands/[command].md` in CLAUDE.md files
